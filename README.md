# 🛒 Supermart Grocery Sales Dashboard

An interactive retail analytics dashboard for exploring grocery sales performance across Tamil Nadu from January 2015 to December 2018.

## 🌐 Live Demo

**[View the Live Dashboard](https://dofekrishna4-dev.github.io/supermart-dashboard/)**

## 📊 Overview

The Supermart Grocery Sales Dashboard brings key retail performance metrics into one interactive interface. Users can explore sales, profit, discounts, order volume, and regional performance through filters and visualizations.

## ✨ Features

- **Key Performance Indicators:** Total sales, total profit, profit margin, orders, and average discount.
- **Interactive Filters:** Filter results by year, region, and product category.
- **Sales Analytics:** Explore retail performance using dashboard charts and summaries.
- **Reset Filters:** Restore the default dashboard view.
- **Light/Dark Theme:** Switch the dashboard's visual theme.
- **Responsive Interface:** View the dashboard in a modern browser.

## 🚀 Getting Started

1. Clone this repository:

   ```bash
   git clone https://github.com/dofekrishna4-dev/supermart-dashboard.git
   ```

2. Open the repository folder.
3. Open `index.html` in a modern web browser.

No backend server is required for the static dashboard.

## 📈 Key Metrics

The dashboard displays metrics such as:

- Total sales
- Total profit
- Profit margin
- Number of orders
- Average discount

Displayed figures reflect the dataset and active filter selections.

## 🎯 Project Objective

The objective of this project is to make retail sales data easier to explore and interpret through an interactive dashboard, supporting data-driven insights into product, regional, and sales performance.
